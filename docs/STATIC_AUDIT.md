上表区间对应脱敏前的原始文本，采用 JavaScript UTF-16 字符索引，不是 UTF-8 字节偏移。报告不包含该值。已通过 `tools/sanitize.mjs` 使用同长度标记脱敏，并重新生成 `readable/` 与 `client/`。原摘要、交付摘要及脱敏区间保存在 `recovered/manifest.json`；本地原文备份已被 `.gitignore` 排除。

`wxAppId`、`appId` 等为客户端公开应用标识，不按凭据处理。`openid`、`unionid`、`session_key` 等作为接口字段名出现，本身不是登录状态或用户数据；没有据此认定持有用户会话。

常见提供商令牌格式、JWT、私钥 PEM 标记未发现。解码 JSON 中未发现额外敏感名称下的硬编码凭据。

`recovered/manifest.json` 未发现绝对本机路径或用户身份/会话字段。仅记录应用标识及导出文件信息。初筛中形如游戏资源 `home/…` 的路径不属于用户主目录，未列为隐私信息。

## 交付限制

这是静态检查，不能证明任意字符串都不是凭据，也不能验证凭据有效性。没有分析运行期网络响应、账号登录态、服务端数据库；这些内容不属于本次导出范围。检查结果针对上述范围与检查时点，后续若重新导出或生成副本，应再次核对脱敏是否保留。

独立编写的备用 `prototype/` 不属于原游戏恢复内容，应排除在本次正式交付之外。
